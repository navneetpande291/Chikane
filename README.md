# Chicane Website — GitHub Pages

## Files
- index.html — page structure
- style.css — all styling
- script.js — navigation, carousel, counters, trailer modal and demo form

## GitHub Pages
Upload all files to the repository root. Then go to Settings → Pages → Deploy from a branch → main → / (root) → Save.

The page uses Google Fonts from fonts.googleapis.com. No build step is required.
